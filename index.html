· 修复两处：① qc.get_fx() 改为多端点冗余（open.er-api.com/v6 → exchangerate-api v4，timeout 12 秒），新增 _parse_fx_payload() 解析助手；② daily_sop.py 步骤6 改为汇率陈旧时仍执行 SELL、仅禁止 BUY——依据是止损阈值为价格口径（现价 vs 成本×0.92 / entry_high×0.92），与汇率无关；汇率只影响金额换算，不影响「是否该卖」。
· 为什么这条比任何单个数字都重要：一个「网络抖动 → 止损不执行」的缺陷是会系统性累积的——若每次汇率接口抖动都能拦下一次硬止损，那么持仓的止损纪律实际取决于第三方 API 的可用性，而不是本基金自身的规则。本轮已把这条依赖切断。
